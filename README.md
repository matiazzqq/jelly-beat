## 🌊 О игре

**JELLY BEAT** — четвёртая игра вселенной **DEEP ABYSS** и первая **ритм-игра** во всех твоих вселенных. Музыка генерируется в реальном времени (kick, hi-hat, бас), а медузы всплывают в такт биту.

Вокруг каждой медузы сжимается кольцо-таймер. В момент, когда кольцо совпадает с телом медузы, нужно тапнуть. Точность определяет оценку: PERFECT, GOOD или MISS.

---

## ✨ Особенности

- 🎵 **Процедурная музыка**: бит synthes-ится через Web Audio API, без MP3.
- 🎐 **Кольцо-таймер**: визуальный индикатор точности вокруг каждой медузы.
- 🎯 **Окна точности**: PERFECT ±0.09с, GOOD ±0.20с.
- 🔥 **Комбо-множитель**: серия попаданий увеличивает очки до ×3.
- ⚡ **Энергия**: Miss сливает её; на нуле трек провален.
- 📈 **3 сложности**: 90 / 110 / 130 BPM с растущей плотностью нот.
- 🏅 **Система оценок**: S / A / B / C / D / F по точности.
- 📱 **Мульти-тач**: можно бить по нескольким медузам одновременно.

## 🕹 Управление

| Действие | Как |
|----------|-----|
| Удар по медузе | Клик мышью / тап пальцем в момент совпадения кольца |

Больше ничего не нужно — только чувство ритма.
